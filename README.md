# MMU (Music Metadata Utility)
MMU is a utility that allows you to easily create/edit metadata for music files using a step-by-step layout.

# Current Features
MMU currently allows you to edit song metadata & make m3u8 playlists.

# Future Features
Future features planned are the ability to natively sync to physical MP3 player units, along with potentially having custom firmware.
